# SluiceNet
# следите за новостями в Discorde https://discord.gg/t5Q79tdgyd

**Обход DPI-блокировок для Windows — в один клик.**
Приложение для Windows: YouTube, Discord, Roblox (включая картинки и аватарки) и другие сайты работают без VPN и без прокси. Один установщик, одна кнопка «Запустить».

> Sluice — шлюз: приоткрываешь заслонку и пропускаешь поток. Приложение не ломает стену и не меняет ваш IP — оно аккуратно проводит трафик мимо DPI.

---

  # Возможности

- **Один установщик** — `SluiceNetSetup.exe` содержит всё: лаунчер, движок, драйвер, списки доменов. Никаких архивов, зависимостей и настроек вручную.
- **Запустить / Остановить** — управление обходом одной кнопкой, работа в трее.
- **Готовые профили** под разные провайдеры и типы блокировок:
  1. **ВСЁ РФ** — авто-детект: движок сам замечает заблокированные домены и дописывает их в список обхода;
  2. По списку (Discord, YouTube, Roblox);
  3. Простой fake (запасной);
  4. Hostfakesplit (второй запасной);
  5. Только Discord + Roblox (голос);
  6. **Roblox картинки/аватарки** — CDN `*.rbxcdn.com`, превью, текстуры;
  7. Roblox запасной (multidisorder).
- **Проверить обход** — встроенный тест: реальные TLS-рукопожатия до YouTube, Discord, Roblox CDN, Google. Сразу видно, что работает, а что нет.
- **Диагностика драйвера** — проверка, что WinDivert действительно перехватывает трафик; если нет — в логе точная причина (нет прав администратора, антивирус, «Целостность памяти», другая программа держит драйвер).
- **Авто-перезапуск** — если `winws.exe` упал, лаунчер поднимает его сам (до 3 раз подряд).
- **Чистый старт** — перед запуском гасит другие программы обхода, которые держат драйвер.
- **Редактируемые флаги** — профили и аргументы хранятся в `config.json`, можно править через диалог «Флаги…».
- **Живой лог** — stdout/stderr движка прямо в окне, плюс файл `logs\launcher.log`.
- **Раздать на телефон** — раздача обхода через мобильный хотспот Windows.
- **Выключить обход полностью / Выйти полностью** — гарантированно останавливает движок и выгружает драйвер; интернет возвращается к прямому соединению.
- Тёмный интерфейс с акрилом, UAC-манифест (запрос прав администратора при старте), без консольных окон.

## Установка

1. Скачайте `SluiceNetSetup.exe` (файл прикреплён к репозиторию; раздел Releases появится с первым релизом).
2. Запустите, выберите папку (по умолчанию `Program Files\SluiceNet`), нажмите «Установить».
3. Ярлык **SluiceNet** появится на рабочем столе и в меню Пуск.
4. Откройте SluiceNet → профиль «1) ВСЁ РФ» → **Запустить** → **Проверить обход**.

Если стояла предыдущая версия приложения — установщик сам перенесёт настройки и списки и уберёт старые ярлыки.

Удаление: «Параметры → Приложения → SluiceNet» или `uninstall.exe` в папке программы.

## Требования

- Windows 10 / 11 x64
- Права администратора (лаунчер запрашивает их сам)
- Отключённая «Целостность памяти» (Memory Integrity), если она блокирует драйвер WinDivert — лаунчер напишет об этом в лог
- Антивирус может ругаться на драйвер перехвата пакетов — добавьте папку программы в исключения

## Чего SluiceNet НЕ делает

SluiceNet обходит **DPI-блокировки провайдера** (когда соединение рвётся или подменяется DNS на уровне сети). Он **не меняет ваш IP-адрес**. Поэтому сайты, которые сами банят по стране/региону — например, `openrouter.ai` (Cloudflare WAF) или Adobe Podcast — через него не откроются: для них нужен VPN. Встроенная кнопка «Проверить обход» помогает отличить одно от другого.

## Как это работает

Движок `winws.exe` через драйвер [WinDivert](https://github.com/basil00/WinDivert) перехватывает исходящие пакеты к доменам из списков и применяет desync-стратегии (fake, multisplit, multidisorder, hostfakesplit), которые делают TLS-рукопожатие «невидимым» для DPI провайдера. Трафик идёт напрямую к сайту — без посредников, прокси и туннелей. Списки доменов (`lists\*.txt`) и стратегии подобраны под РФ; исключения (`list-exclude.txt`) защищают банки, госуслуги и Steam от лишнего вмешательства.

## Структура

```
SluiceNet\
├─ SluiceNet.exe        лаунчер (GUI)
├─ winws.exe            сетевой движок обхода
├─ WinDivert.dll/.sys   драйвер перехвата
├─ cygwin1.dll          среда исполнения winws
├─ config.json          профили и настройки
├─ lists\               списки доменов и IP
│  ├─ list-general.txt    основной список обхода
│  ├─ list-roblox.txt     Roblox + CDN картинок
│  ├─ list-exclude.txt    исключения (банки, госуслуги…)
│  ├─ list-auto.txt       авто-детект (дописывает движок)
│  └─ ipset-*.txt         IP-диапазоны
├─ *.bin                шаблоны пакетов для desync
└─ logs\launcher.log    журнал
```

## Сборка из исходников

Нужен только Windows и .NET Framework 4.x (компилятор `csc.exe` уже в системе). Внешние зависимости не скачиваются.

```
build_l.cmd                    → bin\SluiceNet.exe
tools\build_icon.cmd           → bin\SluiceNet.ico
tools\setup\build_setup.bat    → bin\SluiceNetSetup.exe
```

Исходники: `src\Launcher.cs` (лаунчер), `tools\setup\Setup.cs` (установщик). Бинарные компоненты (`winws.exe`, `WinDivert`, `cygwin1.dll`, `.bin`) взяты из открытых проектов ниже и лежат в `bin\`.
